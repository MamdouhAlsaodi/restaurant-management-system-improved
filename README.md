# Restaurant Management System — Improved React Edition

A React + Vite single-page application for managing restaurant orders, menu items, discounts, sales analytics, and settings, with browser local-storage persistence. The interface supports Arabic (RTL), English, and Portuguese. It uses Tailwind CSS from a CDN.

## Features

- Order taking with a shopping cart and checkout flow
- Menu management (add/edit menu items)
- Discounts
- Sales analytics and order history
- Settings, persisted via local storage

## Run Locally

Prerequisites: Node.js

1. Install dependencies:
   ```
   npm install
   ```
2. Start the dev server:
   ```
   npm run dev
   ```
3. Build for production:
   ```
   npm run build
   ```

## Tech Stack

- React 19, TypeScript, Vite
- Tailwind CSS (CDN)
- lucide-react icons
